# Changelog

## [2.1.0] - 2026-05-27

- Use identical defaults for timeout config
- Do nothing when cron config is empty
- Make jobs unique
- Document failed job handling

## [2.0.0] - 2026-05-27

- Add support for Laravel 13
- Remove support for Laravel 10 and 11

## [1.2.0] - 2025-03-06

- Add support for Laravel 12

## [1.1.0] - 2024-11-11

- Make frequency adjustable using crontab syntax

## [1.0.0] - 2024-11-09

- Initial release 🎉
